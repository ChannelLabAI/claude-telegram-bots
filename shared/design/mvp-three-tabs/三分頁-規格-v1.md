## 0. 一句話

把小編從「只能產出」補成完整循環：**產出（內容產製）→ 存起來（我的內容）→ 看得到資料去哪（資料稽核）→ 可調預設（設定）**。

## 1. 共通
- 品牌：奶油裸粉，沿用 content-production.html 樣式。
- 頂欄四分頁改為**可點擊路由**：`/content-production`（現有）＋新增 `/my-content`、`/data-audit`、`/settings`；當前頁高亮。
- 全部需登入（沿用現行 session）；身分列沿用「安全存取路徑」規格的兩態（本人／共用訪客）。
- 錯誤與空狀態一律中文人話，無英文錯誤碼。

---

## 2. 我的內容（/my-content）

**用途**：使用者的內容庫 —— 產製過的作品存放、回來看與再用的地方。

- **列表**：作品卡片格狀排列。每張：縮圖（主視覺，無圖則文字預覽）、主題、平台 badge、語氣 tag、產製日期、狀態（草稿／已核准）。
- **篩選／搜尋**：依平台、日期；關鍵字搜尋主題。
- **卡片點擊 → 詳情**：所選方向、完整文案、產出的圖片組。
- **每張操作**：開啟／複製文案／下載圖／再生成／刪除。
- **空狀態**：「還沒有內容 —— 去『內容產製』做第一支 →」。
- ⚠️ **資料隔離（硬性 AC）**：列表端點**只回傳 `WHERE user_id = session user.id`**；共用訪客帳號看到的是共用池且介面標「共用示範內容」。
  - 現況已驗：寫入綁 user.id（mvp-server.ts:377）、produce 讀 proposal 為 `id=? AND user_id=?`（:349）；本頁是**第一個讀回端點**，隔離規則在此第一次落地，務必釘死。

## 3. 資料稽核（/data-audit）

**用途**：讓使用者看得到「每支內容的資料去了哪」—— 透明、可信。**這是把 content-production.html:154「🌿 這支內容的資料去了哪（可稽核）」內嵌鏈做成完整頁。**

- **資料來源**：後端已在寫 `content-production-dataflow.jsonl`（mvp-server.ts:380，event=content_produce，含 production_id/proposal_id/provider/model/selected_by/at）。本頁讀它投影，不新建資料源。
- **每支內容一條資料流鏈**（沿用現有節點語意）：
  `你的輸入 → 內容生成（Claude，現接引擎）→ 圖片生成（影像模型）→ 合成／排版（本地·不外送）→ 儲存（你的內容庫·綁你的帳號）`
  - 每一步標明**本地／不外送** vs **送外部 API**（哪個模型、哪家），顏色區分。
- **時間軸／紀錄**：每筆列 產製時間、用的引擎與模型、資料儲存位置、由誰產製（selected_by）。
- **信任摘要（據實、非行銷）**：如「圖文合成在本地完成、不外送」「你的內容存在你自己的帳號下，不交第三方保管」—— 每句都對得上 dataflow 紀錄，**不得寫沒有紀錄支撐的保證**。
- **空狀態**：「還沒有可稽核的產製紀錄」。
- ⚠️ 稽核紀錄同樣**依 user_id 過濾**（只看自己的產製流）。

## 4. 設定（/settings）

**用途**：帳號、品牌預設、平台連結。

- **帳號**：姓名、登入信箱、**身分層級（本人／共用檢視帳號·Demo）**、登出。共用訪客顯示「切換為我的帳號」（沿用存取路徑規格）。
- **品牌預設**（讓產製自動套用）：品牌色（奶油裸粉）、預設語氣、常用平台。
- **平台連結**：IG／YT／TikTok 授權狀態；Phase 1 顯示「待授權」＋註「實際發布需各平台 API 授權（Phase 2）」。
- **偏好**：語言等。
- 管理員專屬項（若有）對 member／共用訪客隱藏。

## 5. 需老兔／小米決策或授權
- 平台 API 連結（IG/YT/TikTok 實際發布）屬 **Phase 2**，需老兔核預算，本版只做 UI 佔位與「待授權」狀態，不接真 API。
- 設定頁若含「改品牌／預設」寫入，沿用現行寫入把關；不涉授權變更。

## 6. 驗收準則（AC 草案；anya 精修）
1. 頂欄四分頁皆可點擊並正確路由、當前頁高亮；三新頁不再是死 span。
2. 我的內容列表**只顯示登入者自己的內容**（WHERE user_id）；空狀態有引導。
3. 資料稽核讀 dataflow.jsonl 投影，逐支內容顯示資料流鏈與本地/外送標示；信任摘要每句對得上紀錄。
4. 設定頁顯示帳號＋身分層級＋品牌預設；平台連結為 Phase 2 佔位＋「待授權」。
5. 全程中文人話、無英文錯誤碼；三頁皆需登入。
6. **live_verify 能失敗**：以兩個帳號驗「我的內容」與「資料稽核」互不可見對方資料（非只驗成功路徑）。
